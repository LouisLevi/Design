# Auswahl: fertige Renderings

Pro Wohnung eine Innenansicht und eine Luftansicht (`Wohnung 1 Innenansicht.JPG` …
`Wohnung 6 Luftansicht.JPG`, 1364×768).

Aufbereitet mit `python3 renderings/aufbereiten.py` nach
`renderings/fotorealistisch/auswahl/` (1920×1080, JPEG): Weißabgleich auf
Tageslicht, einheitliche Helligkeit, Hochskalierung mit FSRCNN, reinweißer
Hintergrund bei den Luftansichten.
